# LegoNxt

An object oriented interface for talking to the LEGO NXT brick.

## Archived

This project has been archived. It previously worked to control NXT bricks via real-time from a Linux or macOS system. It didn't (yet?) support sending programs to the NXT.

Since this is open source, feel free to fork it and fix it up! Send me a message if you do, or if you have any questions.
